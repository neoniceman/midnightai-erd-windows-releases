# Midnight ERD for Windows

Windows x64 downloads and automatic updates for Midnight ERD.

- [Download the latest Windows release](https://github.com/neoniceman/midnightai-erd-windows-releases/releases/latest)
- [Windows license purchase](https://midnightai.lemonsqueezy.com/checkout/buy/21783e7f-1271-47bc-bed0-3db3be2a74ae)

Install the Setup EXE to receive automatic updates from this repository. A Windows license is required; macOS licenses and releases are separate.

This repository hosts release binaries and update metadata only. Application source code is not published here.

The initial v1.0.2 Windows build is unsigned. Windows application-control policies may block it; see release notes for validation limits.
